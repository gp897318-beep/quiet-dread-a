One code review comment that approves a pull request while carrying quiet
existential dread. `main.ts` writes the single line to `/output/entry.txt`:

> Approved. Every line makes sense on its own, which is exactly what worries me.

Run it with Node 22: `node main.ts` (or set `MAKEFUN_OUTPUT_DIR` to choose
the output directory).
